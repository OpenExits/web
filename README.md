# OpenExits Web

Homepage, public map, and the contribution panel for the
[OpenExits](../specification/) standard and [Commons](../commons/).

- `backend/` — Flask API (panel, moderation, publisher bot). Imports the exact same
  `openexits-validator` package the Commons CI runs.
- `frontend/` — React 19 + Vite + TypeScript + Tailwind; MapLibre GL map; EN/FR.
